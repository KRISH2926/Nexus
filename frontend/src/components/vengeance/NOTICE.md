Vengeance UI component sources were adapted for the React 18/Create React App
application:

- Animated Button: https://github.com/Ashutoshx7/VengeanceUI/tree/main/public/r/animated-button.json
- FAQ Accordion: https://github.com/Ashutoshx7/VengeanceUI/tree/main/public/r/faq-accordion.json

The button was adapted to use a reduced, CSS-only hover treatment instead of
the registry component's Framer Motion dependency. The accordion was adapted
to the existing application styles and native button semantics. The upstream
MIT license is included in this directory.
